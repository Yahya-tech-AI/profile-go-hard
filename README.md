# ∞ Profile Go Hard

> **Your profile. Your identity. Your aura.**

Profile Go Hard (PGH) is a personal profile platform where people can create, customize, and share their own digital identity.

PGH is built around one simple idea:

**You shouldn't need someone else to design your profile. You build it yourself.**

---

## 🚀 What is PGH?

Profile Go Hard lets users create their own personalized profile and control how they present themselves online.

Users can:

* 👤 Create an account
* 🎨 Design their own profile
* ✨ Customize their profile identity
* 🧑 Create a custom profile icon
* 📝 Add a bio
* 🌐 Add social links
* 💚 Add interests
* 👀 View their public profile
* ⚙️ Manage their settings

## ⚡ Running Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Enter the project:

```bash
cd profile-go-hard
```

Install dependencies:

```bash
npm install
```

Start the local server:

```bash
npm start
```

Then open the local address shown in your terminal.
